# Pearl Gorilla Safaris - East African Wildlife Tours

Premium East African safari experiences specializing in mountain gorilla trekking, chimpanzee tours, and authentic wildlife adventures in Uganda, Rwanda, and Kenya.

## Getting Started

This application is built with React, Vite, and Tailwind CSS for an optimized East African safari booking and tour planning platform.

### Prerequisites
- Node.js (v16 or higher)

### Installation & Running Locally

1. Clone this repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key (if using AI features)
4. Run the development server:
   ```bash
   npm run dev
   ```

The app will be available at `http://localhost:3000`

### Building for Production

To build for deployment on Netlify:
```bash
npm run build
```

This generates optimized files in the `dist/` directory ready for deployment.

### Deployment on Netlify

1. Connect your Git repository to Netlify
2. Set build command: `npm run build`
3. Set publish directory: `dist`
4. Deploy!
